今天，我的个人博客上线了。

一开始只是想做一个属于自己的网址：不依赖某个社交平台，也不需要复杂的服务器。后来一步一步把它搭起来——用 Markdown 写文章，用 GitHub 保存网站代码，再交给 Cloudflare 自动发布。

## 今天完成了什么

我先在 Mac 上准备好了写网站需要的工具：代码编辑器 VS Code、Node.js 和 Git。接着创建了博客项目，设置了博客名称“虾基尔车”和简介“在读硕士”。

网站在自己的电脑上可以先预览，确认样式没有问题后，再把项目放进 GitHub 仓库。GitHub 像是网站代码的云端备份，也是自动发布的起点。

最后，我把 GitHub 仓库连接到 Cloudflare Pages。它负责把网站放到互联网，生成了这个可以直接访问的网址：<https://xiajierche-blog.pages.dev/>。这一步不需要购买服务器。

## 以后怎样写新文章

每篇文章都是一个 Markdown 文件，放在 `src/data/blog` 文件夹里。文件顶部写文章标题、简介和日期，下面直接写正文。保存后，在本地预览里就能看到新的文章。

## 怎样把更新发送到网站

以后修改文章或页面后，打开 VS Code 左侧的“源代码管理”：

1. 在“更改”里确认这次要上传的文件；不相关的文件不要勾选。
2. 点击文件旁边的 `+`，把它加入这次更新。
3. 在上方填写一句说明，例如“发布新文章”。
4. 点击蓝色“提交”按钮，先把这次更新保存到本地 Git 记录里。
5. 点击 `main` 右边的同步图标，或点击显示 `↑` 的同步更改，把更新发送到 GitHub。

GitHub 收到更新后，Cloudflare Pages 会自动重新发布网站。通常等待一两分钟，刷新网址就能看到新内容。

今天的第一篇文章，也从这里开始。
