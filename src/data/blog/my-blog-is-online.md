今天，我的个人博客上线了。

一开始只是想做一个属于自己的网址：不依赖某个社交平台，也不需要复杂的服务器。后来一步一步把它搭起来——用 Markdown 写文章，用 GitHub 保存网站代码，再交给 Cloudflare 自动发布。

整个过程里，最有用的发现是：个人网站不一定很复杂。写文章就是新建一个文件；更新网站就是把改动同步到 GitHub。网站部署完成后，会自动生成一个可以访问的网址。

目前博客还是很简单，只有名字、简介和一个空白的文章列表。但我喜欢它还没有被填满的状态。以后可以在这里记录学习、阅读、生活，或者只是写下一天里想留住的事情。

这篇文章也是第一次更新。
